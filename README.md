# Реестр штрафов

Веб-приложение для учёта нарушений дедлайнов подрядчиками и расчёта штрафов по условиям договоров. Реализовано по требованиям из [Aiken.md](Aiken.md).

## Разделы

- **Правила** — формулы расчёта штрафа по паре «подрядчик + тип задачи/договор».
- **Нарушения** — фиксация срывов дедлайнов с автоматическим расчётом суммы штрафа и журналом со статусами (Новое / Счёт выставлен / Оплачено).
- **Сводка** — начислено / оплачено / к оплате по каждому подрядчику и валюте.

## О файле `index.html`

Это код опубликованного Claude Artifact. Общие данные (правила, нарушения) хранятся через рантайм-возможность `db` платформы Claude (`window.claude.use("db")`) и синхронизируются в реальном времени между всеми, кто открыл приложение по ссылке артефакта.

Этот HTML **не будет работать как самостоятельный сайт** (например, на GitHub Pages) — объект `window.claude` и хранилище данных существуют только внутри просмотрщика Claude Artifacts. Этот репозиторий служит хранилищем исходного кода и историей изменений; рабочая копия приложения — по ссылке артефакта.
