# Реестр штрафов

Веб-приложение для учёта нарушений дедлайнов подрядчиками и расчёта штрафов по условиям договоров. Реализовано по требованиям из [Aiken.md](Aiken.md).

## Разделы

- **Правила** — формулы расчёта штрафа по паре «подрядчик + тип задачи/договор».
- **Нарушения** — фиксация срывов дедлайнов с автоматическим расчётом суммы штрафа и журналом со статусами (Новое / Счёт выставлен / Оплачено).
- **Сводка** — начислено / оплачено / к оплате по каждому подрядчику и валюте.

## О хранении данных

Приложение умеет работать в двух режимах:

- **Внутри Claude Artifact** — общие данные (правила, нарушения) хранятся через рантайм-возможность `db` платформы Claude и синхронизируются в реальном времени между всеми, кто открыл приложение по ссылке артефакта. Это режим для командной работы.
- **На GitHub Pages (или любом другом обычном хостинге)** — объекта `window.claude` там нет, поэтому приложение автоматически переключается на `localStorage` браузера. Работает только для одного человека на одном устройстве, без общего доступа команды: данные не покидают этот браузер.

Для совместной работы команды используйте ссылку на Claude Artifact.
